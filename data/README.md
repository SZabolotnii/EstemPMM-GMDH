# Data Directory

This directory is intentionally empty in the initial `EstemPMM-GMDH` package repository.

The package tests and core synthetic experiments do not require private data. Application experiments that reference drilling, Gas Turbine, SRU, insurance, or other domain datasets should read those files from a local research workspace or a separate data store with license tracking.

Do not commit raw or processed application data unless the redistribution license is explicit.
